# Founding fleet pictures

The profile pictures of the four founding fleets: the flat Regent crown
(`repos/design-system/logos/regents-crown-flat-light.svg`), one colour pair per type, 1200 × 1200.

| Fleet | Background | Crown |
| --- | --- | --- |
| Classic #1 | `#0F1B3D` midnight navy | `#F2C14E` gold |
| Syndicate #1 | `#0B3B2C` deep green | `#E9F5EE` ivory |
| Accelerant #1 | `#1C1210` ember black | `#FF5A1F` flame orange |
| Cascade #1 | `#06263F` deep blue | `#47D7EC` water cyan |

`uv run make.py` draws them again. Each goes to IPFS and is shown from
`https://media.regents.sh/ipfs/<cid>`; the fleet's on-chain profile names that link.
